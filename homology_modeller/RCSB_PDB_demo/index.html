Advanced Search Tools

Advanced Search

Find PDB structures and Computed Structure Models (CSM) by combining queries from tools in this suite: Attribute Search, Sequence Similarity, Sequence Motif, 3D Similarity, and 3D Motif with 'AND' logic.

Sequence Similarity Search

Find structures that contain a similar nucleotide or protein sequence using the MMseqs2 method.

Chemical Search

Find small molecules by combining queries from the tools in this suite: Chemical Attributes and Chemical Similarity Search with 'AND' logic.

Browse Annotations

Find PDB structures using annotations from various ontologies and hierarchical classification schemes, e.g. Disease Ontology, Molecular Function.
