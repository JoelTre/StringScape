StringScape Homology Modeller

This app builds homology models of protein complexes (including DNA, RNA, small molecule ligands, and ions) by aligning AlphaFold models onto a reference structure from the Protein Data Bank. Simply enter a PDB ID to use as a reference structure (i.e. template) and the AlphaFold/UniProt IDs of the proteins to be aligned. You can also upload two files from the STRING database to allow this app to automatically find the AlphaFold models to align (though it can make mistakes).

This app has been specifically built to be easy to use to democritise access to homology modelling. Send feedback to stringscape.net/contact

Reference: Loading...

This app builds homology models of protein complexes by aligning AlphaFold models onto a reference structure from the Protein Data Bank. This involves multiple steps:

  1. Load the reference structure from the Protein Data Bank and load the AlphaFold structures from the AlphaFold database. If no AlphaFold model is available, the app just uses the protein sequence without any structural information.
    • Optional: If STRING files have been uploaded, the app searches each of the reference PDB chain sequences in the FASTA file for matches and then uses the alias file to get the UniProt IDs for each match, which are then used to fetch the AlphaFold models.
  2. Align each of the chain sequences from the reference with each of the AlphaFold sequences. Semi-global alignment fits each reference chain within an AlphaFold sequence, allowing for extra AlphaFold residues at either end. Alignment Settings also offers local Smith–Waterman and global Needleman–Wunsch as alignment methods.
  3. Calculate distance matrices. The distance matrix captures the spatial relationships between residues within each chain and, for the reference structure, between each chain.
  4. Build the morph distance matrix. The distance matrices of the reference structure and the AlphaFold models are combined to create the morph distance matrix. The Reference PDB and AlphaFold sliders determine the blend of shared intra-chain distances and each values influence on the simulation.
  5. Align AlphaFold models onto the reference structure. This has two phases: In phase 1, the AlphaFold structures are aligned to the reference structure via rigid-body Template Modelling alignment. In phase 2, an overdamped elastic simulation is run to mould the AlphaFold structures to the reference structure.
  6. Convert the simulation result into a mmCIF format and display in a Mol* viewer. The mmCIF file can then be downloaded.
