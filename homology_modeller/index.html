StringScape Homology Modeller

This app builds all-atom homology models of protein complexes (including DNA, RNA, small molecules, ions, and lipid membranes) by aligning AlphaFold models onto a reference structure from the Protein Data Bank and computing membrane positions. Enter search terms, UniProt IDs, or sequences and click 'Find PDBs', or enter reference PDB IDs directly, then click 'Build Homology Model'. Or, use an example below.

This app has been specifically built to be easy to use to democratise access to all-atom homology modelling. Send feedback to stringscape.net/contact

This app is also available as a feature within the main StringScape application (in the Structures view, where all PDB files from a species are displayed and any can be clicked on to build a homology model). This app is open source under an Apache-2.0 licence. View source code

This app works without an AI connected, but the models will likely be more accurate if you connect an AI.

Tips
  • Using search terms can identify the wrong files from the Protein Data Bank. I recommend using the specific PDB IDs for the structure you want modelled.
  • Use animation keyframes to compare two model settings. Reduce the animation to one keyframe, set “Colour proteins by” to “Keyframe conformation difference”, click “Duplicate keyframe”, then adjust a physics parameter to see its effect on the conformation. Play the animation to watch the model morph between the two conformations.
  • If part of a protein looks misplaced, use Shift+Drag to pull it toward the expected position. The physics simulation will relax from the new conformation.
  • Click a residue, alignment letter, or matrix cell to highlight the equavalent ones in the others (these are synced). Shift+click in the 3D viewer to select more than one residue at once.
  • Open the Validation report to inspect where restraints are well supported and where the model does not yet satisfy them.

Group simulation

Control which subunits relax together and when each group stops.

How group simulation works

Each subunit serves once as a core. Its group includes subunits with any residue within the neighbour distance when that group starts. Each model runs two passes, each using half the maximum waiting time per group. Running time excludes pauses. Colours reset for the second pass. Overlapping groups share moving subunits; each core has its own stopping criteria. The residue budget applies when the next build starts. Additional groups start only when their combined active, unlocked residue count fits the budget; overlapping residues count once. A single group may exceed it. Dynamic starts at 100 and adjusts toward 5.0 steps/s; newer groups may be deferred when the budget falls. Fixed reference residues remain locked.

Reference:

This app builds homology models of protein complexes by aligning AlphaFold models onto one or more reference structures from the Protein Data Bank. This involves multiple steps:

  1. Load one or more reference structures from the Protein Data Bank and load the AlphaFold structures from the AlphaFold database. If no AlphaFold model is available, the app just uses the protein sequence without any structural information.
    • Optional: If STRING files have been uploaded, the app searches each of the reference PDB chain sequences in the FASTA file for matches and then uses the alias file to get the UniProt IDs for each match, which are then used to fetch the AlphaFold models.
  2. Align each of the chain/polynucleotide sequences from the reference with each of the AlphaFold sequences. Semi-global alignment fits each reference chain/polynucleotide within an AlphaFold sequence, allowing for extra AlphaFold residues at either end. Alignment Settings also offers local Smith–Waterman and global Needleman–Wunsch as alignment methods.
  3. Calculate distance matrices. The distance matrix captures the spatial relationships between residues/nucleotides/atoms within each chain/polynucleotide/molecule and, for the reference structure, between each chain/polynucleotide/molecule.
  4. Build the morph distance matrix. The distance matrices of the aligned reference structures and the AlphaFold models are combined to create the morph distance matrix. The per-reference PDB and AlphaFold sliders determine the blend of shared intra-chain distances and each values influence on the simulation.
  5. Align AlphaFold models onto the reference structure. This has two phases: In phase 1, the AlphaFold structures are aligned to the reference structure via rigid-body Template Modelling alignment. In phase 2, an overdamped elastic simulation relaxes the springs between residues/nucleotides/atoms. AlphaFold spring contributions are weakened where PAE indicates uncertain relative placement or pLDDT indicates uncertain local structure; local Cα angular and pseudo-dihedral restraints help preserve backbone bends and twists. Build Settings controls these effects. Each reference is used independently to build a draft model, keeping aligned interior residues locked while successive groups of nearby subunits relax.
    • Adding membranes: The app estimates whether a protein complex resides in a lipid membrane and displays its predicted membrane position, curvature, and placement confidence.
  6. Combine drafts when multiple references are loaded. Completed drafts are structurally TM-aligned and equivalent subunits are matched. Their sequences are combined, residue centres and spring values are averaged using the reference influence sliders, and unmatched subunits are retained. The combined model then undergoes group simulations with active subunits free of reference coordinate locks.
  7. Convert the simulation result into a mmCIF format and display in a Mol* viewer. The mmCIF file can then be downloaded.

TM-score (Phase 2) is recalculated for each graph sample from equivalent Cα positions in the current simulated model and the reference, in the fixed build coordinate frame. Higher (up to 1) means closer agreement. The TM-Score (P1) value above is the fixed result from the initial Phase 1 chain alignments.
RMSD (Phase 2) is the root-mean-square distance between equivalent Cα atoms in the current simulated model and the reference, in ångströms (Å). Lower means closer. The RMSD (P1) value above is fixed at the initial Phase 1 result.
Weighted spring-length error is the square root of the mean stiffness-weighted spring potential, in arbitrary units (a.u.). Lower means the active spring network is more relaxed. It is neither an RMSD nor a physical energy.
Average residue speed is the mean distance each simulated residue moves per second between samples, in Å/s. Lower means the structure is changing more slowly.
Dynamic max sim residue count is the adaptive budget for concurrent active residues, targeting 5.0 simulation steps/s. Available in dynamic mode.
Simulation step rate is the number of completed simulation updates per second (steps/s), measured over a rolling two-second window. Higher means faster simulation throughput.
Max residue speed of the core subunit is the greatest residue speed in the current core, measured over completed simulation steps in a short running-time window. It determines when the next group starts. With concurrent groups, the plot shows the highest speed across their cores; each core has its own stopping criteria.
Restraint satisfaction shows the mean agreement between active spring lengths and their target distances. A perfect match is 1.0; the score decreases as springs stretch or compress.
Overall model confidence combines distance-evidence support and spring satisfaction from the available restraints. Higher is better; it is a heuristic, not a calibrated probability.
Membrane placement confidence reports evidence supporting the inferred hydrophobic belt. It is unavailable when no membrane is detected.
If normalised, each line is divided by its own maximum in the displayed time window, so 1.0 is that line’s current window maximum. The three validation scores are sampled intermittently and hold their last values between updates. Vertical lines mark group starts and changes to build controls.

            Validation report
            

                

                    
Open the report after building a model to calculate its local validation metrics.

                    

                

                

                    
Sequence coverage—AlphaFold residues mapped

                    
Restraint satisfaction—Mean spring agreement

                    
Membrane placement confidence—When a membrane is detected

                    
Overall confidence—Combined local score

                

                

                    
Sequence coverage is the percentage of protein residues in the AlphaFold chains that align to at least one reference PDB residue. Each AlphaFold residue is counted once, even if it matches several references. Higher coverage means more of the model has a reference sequence match; it does not measure structural accuracy.
Equation Coverage = 100 × (unique mapped AlphaFold protein residues) / (all AlphaFold protein residues)

                    
Restraint satisfaction is the average agreement between each active protein-distance spring’s current length and its target length. Exact agreement scores 100%; the score falls exponentially as the difference grows, relative to the target distance. It describes fit to the active restraints, not the reliability of those restraints.
Equation Pair score = exp(−|model distance − target distance| / max(2 Å, 0.2 × target distance))
Restraint satisfaction = 100 × mean(pair scores)

                    
Membrane placement confidence measures support for the inferred membrane using hydrophobic density contrast, hydrophobic density inside the belt, effective hydrophobic support, and the detector score. It does not apply forces to the model. If no membrane is detected, it is unavailable.

                    
Overall confidence averages the active residue-pair scores. Each pair combines support from available reference structures, AlphaFold pLDDT and PAE, agreement with its spring target. This is a heuristic consistency score, not a calibrated probability that the model is correct.
Equation Pair confidence = evidence support × restraint satisfaction
Overall confidence = 100 × mean(pair confidences)
