StringScape Homology Modeller

This app builds all-atom homology models of protein complexes (including DNA, RNA, small molecules, ions, and lipid membranes) by aligning AlphaFold models onto a reference structure from the Protein Data Bank and computing membrane positions. Simply enter a search term or a PDB ID to use as a reference structure and click 'Build Homology Model'.

This app has been specifically built to be easy to use to democratise access to all-atom homology modelling. Send feedback to stringscape.net/contact

This app is also available as a feature within the main StringScape application (in the Structures view, where all PDB files from a species are displayed and any can be clicked on to build a homology model). This app is open source under an Apache-2.0 licence. View source code

Tips
  • Using search terms can identify the wrong files from the Protein Data Bank. I recommend using the specific PDB IDs for the structure you want modelled.
  • Use animation keyframes to compare two model settings. Reduce the animation to one keyframe, set “Colour proteins by” to “Keyframe conformation difference”, click “Duplicate keyframe”, then adjust a physics parameter to see its effect on the conformation. Play the animation to watch the model morph between the two conformations.
  • If part of a protein looks misplaced, use Shift+Drag to pull it toward the expected position. The physics simulation will relax from the new conformation.
  • Click a residue, alignment letter, or matrix cell to highlight the equavalent ones in the others (these are synced). Shift+click in the 3D viewer to select more than one residue at once.
  • Open the Validation report to inspect where restraints are well supported and where the model does not yet satisfy them.

This app builds homology models of protein complexes by aligning AlphaFold models onto one or more reference structures from the Protein Data Bank. This involves multiple steps:

  1. Load one or more reference structures from the Protein Data Bank and load the AlphaFold structures from the AlphaFold database. If no AlphaFold model is available, the app just uses the protein sequence without any structural information.
    • Optional: If STRING files have been uploaded, the app searches each of the reference PDB chain sequences in the FASTA file for matches and then uses the alias file to get the UniProt IDs for each match, which are then used to fetch the AlphaFold models.
  2. Optional: If multiple reference files are loaded, identify equivalent chains/molecules between reference files. Sequence alignments between all chains/polynucleotides within and between reference PDBs are performed to find chains/polynucleotides of the same type. Then, a matrix is calculated of the distances between the centres of the chains/polynucleotides/molecules within each reference PDB. The distance matrixes are then uses to identify which chains/polynuclotides/molecules between the references are equavalent.
  3. Align each of the chain/polynucleotide sequences from the reference with each of the AlphaFold sequences. Semi-global alignment fits each reference chain/polynucleotide within an AlphaFold sequence, allowing for extra AlphaFold residues at either end. Alignment Settings also offers local Smith–Waterman and global Needleman–Wunsch as alignment methods.
  4. Calculate distance matrices. The distance matrix captures the spatial relationships between residues/nucleotides/atoms within each chain/polynucleotide/molecule and, for the reference structure, between each chain/polynucleotide/molecule.
  5. Build the morph distance matrix. The distance matrices of the aligned reference structures and the AlphaFold models are combined to create the morph distance matrix. The per-reference PDB and AlphaFold sliders determine the blend of shared intra-chain distances and each values influence on the simulation.
  6. Align AlphaFold models onto the reference structure. This has two phases: In phase 1, the AlphaFold structures are aligned to the reference structure via rigid-body Template Modelling alignment. In phase 2, an overdamped elastic simulation relaxes the springs between residues/nucleotides/atoms. AlphaFold spring contributions are weakened where PAE indicates uncertain relative placement or pLDDT indicates uncertain local structure; local Cα angular and pseudo-dihedral restraints help preserve backbone bends and twists. The controls below the 3D viewer adjust these effects.
    • Adding membranes: The app also calculates weather a protein structure likely resides in a lipid membrane, and calculates the position and curvature of the membrane. The app adjusts the shape of the protein complex to move non-membrane-associated portions of the proteins out of the membrane.
  7. Convert the simulation result into a mmCIF format and display in a Mol* viewer. The mmCIF file can then be downloaded.

Phase 2 simulation history

The graph starts when Phase 2 begins.

TM-score (Phase 2) is recalculated for each graph sample from equivalent Cα positions in the current simulated model and the reference, after rigid alignment. Higher (up to 1) means closer agreement. The TM-Score (P1) value above is the fixed result from the initial Phase 1 chain alignments.

RMSD (Phase 2) is the root-mean-square distance between equivalent Cα atoms in the current simulated model and the reference, in ångströms (Å). Lower means closer. The RMSD (P1) value above is fixed at the initial Phase 1 result.

Weighted spring-length error is the square root of the mean stiffness-weighted spring potential, in arbitrary units (a.u.). Lower means the active spring network is more relaxed. It is neither an RMSD nor a physical energy.

Average residue speed is the mean distance each simulated residue moves per second between samples, in Å/s. Lower means the structure is changing more slowly.

Restraint satisfaction shows the mean agreement between active spring lengths and their target distances. A perfect match is 1.0; the score decreases as springs stretch or compress.

Overall model confidence combines distance-evidence support and spring satisfaction, with a locally weighted membrane adjustment. Higher is better; it is a heuristic, not a calibrated probability.

Membrane placement combines how well non-membrane residues have moved out of the membrane with the strength of the detected hydrophobic belt. It is unavailable when no membrane is detected.

If normalised, each line is divided by its own maximum in the displayed time window, so 1.0 is that line’s current window maximum. The three validation scores are sampled intermittently and hold their last values between updates. Vertical lines mark changes to physics controls.

These controls determine how strongly PAE and pLDDT confidence can weaken AlphaFold-derived spring targets and strengths. Zero ignores that confidence measure; higher values give it more effect. Low PAE means stronger pairwise evidence; low pLDDT weakens local evidence. Unavailable scores leave the corresponding factor unchanged.

Validation report

Open the report after building a model to calculate its local validation metrics.

Sequence coverage—AlphaFold residues mapped
Restraint satisfaction—Mean spring agreement
Membrane placement—When a membrane is detected
Overall confidence—Combined local score

Sequence coverage is the percentage of protein residues in the AlphaFold chains that align to at least one reference PDB residue. Each AlphaFold residue is counted once, even if it matches several references. Higher coverage means more of the model has a reference sequence match; it does not measure structural accuracy.

Equation Coverage = 100 × (unique mapped AlphaFold protein residues) / (all AlphaFold protein residues)

Restraint satisfaction is the average agreement between each active protein-distance spring’s current length and its target length. Exact agreement scores 100%; the score falls exponentially as the difference grows, relative to the target distance. It describes fit to the active restraints, not the reliability of those restraints.

Equation Pair score = exp(−|model distance − target distance| / max(2 Å, 0.2 × target distance))
Restraint satisfaction = 100 × mean(pair scores)

Membrane placement combines two factors: the average local score for moving residues classified as incompatible with the membrane away from it, multiplied by confidence in the detected hydrophobic belt. The local score falls near residues that still conflict with the membrane. If no membrane is detected, this value is unavailable.

Equation Local node score = 1 − strongest nearby membrane-conflict penalty
Pair shift score = mean(two node scores)
Membrane placement = 100 × mean(pair shift scores) × membrane-detection confidence

Overall confidence averages the active residue-pair scores. Each pair combines support from available reference structures, AlphaFold pLDDT and PAE, agreement with its spring target, and a local membrane adjustment where relevant. This is a heuristic consistency score, not a calibrated probability that the model is correct.

Equation Pair confidence = evidence support × restraint satisfaction × [1 − 0.2 × membrane-detection confidence × (1 − pair shift score)]
Overall confidence = 100 × mean(pair confidences)

Independent model-quality assessment

QMEANDisCo from SWISS-MODEL

QMEANDisCo is the default validation method used by the SWISS-MODEL homology modeller. It is a "single model method combining statistical potentials and agreement terms with a distance constraints (DisCo) score. DisCo evaluates consistencies of pairwise CA-CA distances from a model with constraints extracted from homologous structures. All scores are combined using a neural network trained to predict per-residue lDDT scores." (SWISS-MODEL website)

QMEANDisCo requires an email address to send to the SWISS-MODEL server. Enter an email and then press Send to submit the current model to SWISS-MODEL. Opening this report or choosing QMEANDisCo colouring does not submit it.
