# Protein modeller benchmark

Serve this directory alongside the modeller over HTTPS, as on GitHub Pages. Open `/homology_modeller/benchmark/` in Chrome or Edge. Upload a CSV with `PDB ID` and `Reference mappings` columns. Mappings have the form `A:P25732:group=A; B:P25732:group=B`. Connect an output folder and run the queue. External RCSB, AlphaFold and UniProt services must be reachable.

Each PDB ID already completed in the connected folder is skipped, regardless of the input CSV or settings. Failed or interrupted entries can be retried. To run an already completed PDB again with different settings, choose a different output folder. Each entry stores a reference, masked reference, settings, prediction, residue table, result, and overview image when available. The root contains a manifest, summary and residue CSVs, and `benchmark-results.json`; connecting the folder loads existing results. The result JSON can also be opened directly in the results tab.

Biological assembly 1 is the default. If it is unavailable the entry fails instead of silently changing to deposited coordinates. The binding site detector is the modeller's existing detector. When no protein binding-site residues are found, a seeded random segment of up to ten observed residues per protein chain is used. The seed is a deterministic 32-bit FNV-1a hash of `1:<uppercase PDB ID>`; the seed, derivation and selected residues are saved. Non-protein residues are retained.

Distances are Cα distances in the reference coordinate frame, in ångströms. Full reference and target sequences are aligned, then matched by chain and identical residue. Ambiguous chain matches and residues without a matching model residue are left unavailable rather than guessed. Counts use reference residues with observed Cα coordinates; missing coordinates cannot be measured. RMSD is the square root of the mean squared distance of the matched residues. The prediction CIF is exported in the reference frame. Confidence scores range from 0 to 1; sequence coverage is a percentage. Disorder is unavailable when UniProt annotations are unavailable. The overview image is the modeller's pre-simulation snapshot, even when simulation is enabled. The result also records the maximum displacement among matched kept residues as a lock diagnostic.

The results page includes a residue confidence-versus-distance plot restricted to rows explicitly marked `Kept? = No`. Older residue tables without that column are excluded from this plot rather than inferred from alignment status. A separate plot compares the input CSV's `Missing residues (%)` with removed-residue RMSD; rows missing either value are excluded. Percentages are interpreted on a 0–100 scale, with or without a trailing percent sign.

The run completion estimate uses the mean duration of PDBs completed in the current run, adjusted for the current entry's elapsed time. It excludes IDs already completed and is unavailable until one PDB completes or while the queue is paused. It is an estimate, since complex sizes and service response times vary.

Plot colour controls can show PDB IDs or a continuous scale based on per-PDB removed or missing residue counts or percentages. Grey means the selected value is unavailable. Missing-residue values come from the input CSV, not inferred coordinates. The first scatter plot can instead plot one point per PDB, using the mean confidence and distance over that PDB's comparable residue pairs; its trend is fitted to whichever points are displayed. Quadratic trends require at least three distinct x values. Residue tables are rendered only for the selected PDB. Overview images are read from the connected folder on selection, with a display-all option.

Each plot has its own non-disordered-residue filter. When enabled, only reference residue rows with `Non-disordered? = Yes` are used; missing or unknown annotations are excluded rather than assumed ordered. Model-level confidence is the mean of available confidence scores in those reference rows, and RMSDs are recalculated from available distances. Kept/removed counts and percentages are recalculated from classified eligible reference rows. Original missing-residue counts and percentages remain the values from the input CSV, since absent residues cannot be classified using the residue table. Filtered confidence may differ from the modeller's overall confidence, which can include residues not represented in the reference table.

New runs also save per-residue φ and ψ circular differences, their mean torsion-angle difference in degrees, and lDDT-Cα. Backbone angles require N, Cα and C coordinates and an intact peptide bond in both structures. lDDT-Cα considers distinct reference Cα pairs less than 15 Å apart, including inter-chain pairs, using strict error thresholds of 0.5, 1, 2 and 4 Å. Each residue's score averages its comparable neighbour checks; pairs without both predicted Cα atoms are excluded and counted as missing. The summary lDDT is weighted by comparable reference pairs, while the per-PDB scatter points are unweighted means of residues with both confidence and metric values. Reference pairs with no comparable prediction are recorded separately; residues without comparable neighbours have unavailable lDDT. These metrics are computed from reference Cα-containing residues, not absent coordinates. Existing results are not retroactively recalculated; use a new output folder for new runs because completed IDs are skipped.

The comparison viewer reads the original reference and predicted mmCIF from the selected folder and keeps them in the saved reference frame. New runs include AlphaFold pLDDT, the modeller's per-residue mean PAE to represented residues in the same AlphaFold chain, and prediction chain/residue mapping in the residue table. Missing values and older runs are displayed as unavailable. The viewer's backbone-issue and clash colours are Cα-based approximations, not the modeller's exact simulation diagnostics. The viewer offers Backbone, Ball & Stick, Ribbon, Curves and Space filling styles. Ribbon reuses the modeller's ribbon generator with secondary structures inferred from each saved structure; Curves uses a smoothed Cα tube. The modeller's Surface style is not implemented in this comparison viewer.

New runs also save `prediction-residues.csv` and prediction residue metadata in each `result.json`. This covers all predicted protein residues, including those without a reference match, and records the modeller's aligned/locked flags and confidence. The comparison viewer uses this mapping for prediction colours. For older runs, the viewer can recover missing prediction mappings from same-chain sequence alignment to reference rows, but values not present in those rows remain unavailable. Ambiguous prediction identifiers are left unavailable.
