Protein modeller batch

Run a batch process with the modeller app

Open the batch app through a local web serverChrome cannot connect this page to the embedded modeller when opened as a file. From the homology_modeller folder, run python3 -m http.server 8000, then open http://localhost:8000/batch/ in Chrome or Edge.

1. Input CSV

Choose a CSV file.

The CSV must contain these exact column headings:

  • What do you want a model of?
  • Reference PDB IDs
  • AlphaFold IDs, UniProt IDs, or PDB IDs

Cells in the rows of these columns can be empty. The app will process the file row by row, inputting whatever inputs are in that row into the modeller app.

2. Output folder

No folder connected.

3. Connect an AI (optional)

The modeller’s AI connection is used for all rows. Without AI, references use one conformation group.

4. Select species (optional)

If using a batch CSV from StringScape, you do not need to select the species, unless using All_complexes_AI_Input.

5. Settings

The setting you choose below will be used for every run of the batch

Full session: Saves the model, inputs, images, residue data, drafts, animations and modeller working data. Full PAE matrices are omitted.

Most data, but fast: Saves the model, inputs, images, residue data and a 3D-viewer snapshot. Drafts, simulation and animation working data are omitted; available keyframe geometry is retained.

Minimal, fastest: Saves the predicted all-atom model, bond topology, residue confidence scores, thumbnail, membrane details and basic metadata. It keeps the three modelling input fields but omits uploaded files, extra CSV columns, the session, full-size image and other viewer data; some colour options and simulation are unavailable.
